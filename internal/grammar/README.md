# Vendored DuckDB grammar

The files under `duckdb/` are copied **verbatim** from the DuckDB repository
and are load-bearing: the matcher engine interprets them at runtime. Never
edit them by hand — changes happen only by advancing the pin (see PLAN.md,
§ Regeneration workflow).

- Upstream: https://github.com/duckdb/duckdb
- Source tree: `src/parser/peg/grammar/`
- Pinned commit: `d54cbbe3df17e8e5ce68312f483b4155836112aa` (tag `v2.0.0`, 2026-10-20)
- Matching oracle binary: DuckDB CLI `v2.0.0 d54cbbe3df` (the v2.0.0 release
  CLI; see `internal/duckdbsrc`)

The pin follows the oracle binary: grammar, corpus expectations, and the
CLI used to derive them must come from the same commit.

DuckDB is MIT-licensed; see `LICENSE.DUCKDB` at the repository root.
